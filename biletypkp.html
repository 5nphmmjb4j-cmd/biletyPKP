🎫 PKP Intercity → Apple Wallet

Generuj plik .pkpass typu boarding pass z danych biletu PKP Intercity.

⚠️ Ważne: Ten pass to nieoficjalny dokument pomocniczy. Nie zastępuje biletu PKP Intercity i nie jest autoryzowany przez przewoźnika. Używaj go wyłącznie jako wygodnej wizualizacji w Apple Wallet.

📄 Opcja 1: Wgraj PDF biletu

Przeglądarka spróbuje odczytać tekst z PDF. Jeśli się nie uda, użyj formularza poniżej.

✍️ Opcja 2: Wprowadź dane ręcznie

📲 Jak dodać do Apple Wallet?

  1. Wygeneruj plik .pkpass za pomocą tego narzędzia.
  2. Podpisz go certyfikatem Apple Developer (Pass Type ID Certificate + WWDR).
  3. Wyślij podpisany plik na iPhone'a (Mail, AirDrop, iCloud).
  4. Otwórz plik — pojawi się przycisk „Dodaj do Wallet".

Bez podpisu Apple Wallet odrzuci plik.

🔐 Jak podpisać .pkpass?

Potrzebujesz:

  • Konta Apple Developer (płatne)
  • Pass Type ID Certificate (z Certificates, Identifiers & Profiles)
  • WWDR Intermediate Certificate

Narzędzia do podpisywania:

  • Node.js: npm install -g signpass → signpass --certificate cert.pem --key key.pem pass.pkpass
  • Python: biblioteka pkpass
  • macOS: productsign (część Xcode)
